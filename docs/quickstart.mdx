This quickstart guide will show you how to:

1. Build and start the mcp-gateway server locally
2. Add the [context7](https://context7.com/) MCP server in mcp-gateway
3. Connect your Claude Desktop to mcp-gateway to access tools

## Start the server

Clone the repository, build the dashboard and binary, then start the server:

```bash
git clone https://github.com/zcray0326/mcp-gateway.git
cd mcp-gateway
bash scripts/build-dashboard.sh
go build -o mcp-gateway .
./mcp-gateway start
```

This exposes mcp-gateway's streamable http mcp server at `http://localhost:8080/mcp` by default.

## Add an MCP server

1. In another terminal, use the binary you just built to add the context7 MCP server:

```bash
./mcp-gateway register --name context7 --url https://mcp.context7.com/mcp
```

You should see output similar to this:

<Note>
  MCP Gateway also includes a Dashboard UI at `http://localhost:8080/`.
  The dashboard is currently in Beta.
</Note>

## Connect to mcp-gateway

In your Claude Desktop, add the configuration for mcp-gateway MCP server:

```json
{
  "mcpServers": {
    "mcp-gateway": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "http://localhost:8080/mcp",
        "--allow-http"
      ]
    }
  }
}
```

Once you have added the configuration, try asking Claude something simple:

```text
Use context7 to get the documentation for `/lodash/lodash`
```

Claude will then attempt to call the `context7__get-library-docs` tool via MCP Gateway, which will return the documentation for the Lodash library.

</p>

You now have a working MCP setup with a single unified endpoint.
